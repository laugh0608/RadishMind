# 基础镜像 pip 的内嵌告知

本目录只保存 pip 25.0.1 精确 sdist 中、当前 SDK 镜像 `_vendor` 目录缺失的 21 份许可文本。来源成员、原始摘要、交付副本摘要和规范化规则见[证据清单](../license-pip-notices-20261105.json)。两份原文只规范化行尾空白 / 末尾 LF，其余逐字节保留。原始归档没有修改。

候选位置为 `/usr/local/share/radishmind/third-party/pip/`。准备器校验许可与源码指纹分片后才创建目录；构建阶段读取同一安装目录的 pip 元数据，并核对 `_vendor` 全部 280 个文件的集合及摘要，不导入 pip 或内嵌包。版本、元数据重复、缺失 / 额外 / 篡改文件、路径或符号链接错误均拒绝。

当前已通过此前保留的镜像字节离线验证。实际镜像尚未重建或安装这些告知；本目录不替代 pip 修改后源码的伴随交付，也不关闭整体许可条件。
