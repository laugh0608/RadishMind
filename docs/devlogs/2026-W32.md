## 关键决策

- family-ui 是通用参考基线，不替具体项目决定配色、Profile、接入方式、采用状态或迁移顺序。
- RadishMind 主动选择 `Workbench` Profile，并继续采用上游 token 原样镜像与项目 L2 语义别名；这些属于项目策略，不写成家族强制规则。
- `brand` 只表达身份，不再承担主操作语义；注意语义也不等同于品牌或危险语义。
- 上游更新没有改变当前开发顺位；完成 `S1` 复验后仍直接进入 `S2`，不派生新的同层迁移批次。
- 五阶段只表达连续任务路径和当前阶段，不冒充完成进度；桌面不并列五套完整 surface，窄屏也不缩放桌面双栏。
- `S1 R5` / `S2 R3` 只冻结共享视觉语法、真实信息层级、风险表达和响应式顺序；代表性计数、离线 evidence 与当前 Application 不能被解释为全量统计、自动执行或生产就绪。
- 参考 UI 的关键不是额外颜色或阴影，而是“大尺度、低噪声、强主次、柔和实体感”；选择性抬升只服务于当前导航、当前阶段和唯一主对象。
