## 关键决策

- RAG retrieval 的完整权限固定为 `workflow_rag:execute`、`workflow_runs:execute`、`workflow_drafts:read` 与 `workflow_rag_snapshots:read`。
- Tool confirmation 与 Evaluation decision 不自动执行、发布或写回业务真相源；RAG retrieval 与 Tool execution 继续保持至多一次外部副作用和既有 Run 终态顺序。
- 开发测试态授权专题在批次 E 后关闭，不继续派生同层 gate-only 切片。
- Saved Draft 的当前记录继续承担最新可编辑状态，revision 只承担不可变历史证据；恢复创建严格递增的新版本，不倒退 current pointer。
- Provider usage 只接受 Provider 明确上报且满足稳定来源、非负整数和总数一致约束的计数；northbound 投影和应用审查不构成计费凭证。
- 草案内容 `draft_version` 与 lifecycle CAS 分离；archive / unarchive 使用独立 `lifecycle_version` 和 append-only event，不伪造内容 revision，也不级联修改 Definition 或 Run。
