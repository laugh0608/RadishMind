## 验收中发现并收口的问题

- 第一次真实触发暴露 Prompt Plan fixture 与模板变量不一致；fixture 修正后由 canonical owner 重新建立 exact Plan，没有在 runner 中增加兼容 fallback。
- 缺少 quota policy 时 occurrence 在 Provider 前稳定失败，deterministic Campaign 仍保持单实例且零 replay；补齐既有 quota owner 后下一次 exact occurrence 成功。
- Campaign invocation 在权限或 quota 等前置条件失败且没有返回 Run 时，current item 原先会停留在 `running`。现由 Campaign service 将该 item 与 Campaign 一起原子收口为失败终态，未来 no-run failure 不再产生内部状态不一致；历史记录不回填。
- 本地角色目录升为 v2，只为 reader 增加 Prompt publish candidate / runtime assignment 两项最小 read grant；既有 v1 assignment 保持不可变，不静默升级历史成员。
