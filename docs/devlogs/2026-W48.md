## 2026-11-25 单 Agent 任务持久化

新增工作台共享 SQLite 的任务迁移，与既有尝试和产物复用同一事务。两组独立写入者竞争同一工作台执行槽时只有一个成功；相同启动请求并发重提时只有首次提交取得凭据。注入启动、取消和保存回执写入故障后，原确认、尝试、凭据吊销或包写入随事务回滚。测试还覆盖操作身份冲突、所有者配额、旧修订失效、回执重读时撤权和临时来源过期。

在临时数据库关闭重开后，旧活动尝试转为结果未知。可信核对返回旧实例的完整终止证据后才能释放槽，身份不符或证据不完整时继续占用。此处核对输入由测试提供，工作台实际进程交接与跨重启资源清理仍待接线。下一步将正式会话、精确权限与严格 HTTP 接入协调器。[公开交付合同](../contracts/development-task-delivery-v1.md#sqlite-实现与宿主接线)

## 2026-11-25 正式会话的任务计划与交付历史

平台接通九个 HTTP 接口，复用本地会话、当前工作区选择、应用所有权和独立的任务 / 产物授权。创建与修订要求同源 JSON 和 CSRF 校验；固定响应计划记录三文件范围、冻结镜像与执行器摘要。任务详情分别返回修订、准备、启动、取消、预览和保存的资格。元数据请求不创建尝试。

在隔离 SQLite 上经过平台 HTTP 处理器提交计划、修订并关闭重开平台后，同一 Cookie 能按原请求找到任务，重复提交创建仍返回修订 1，精确详情返回当前修订。撤销开发者角色后，查询既有回执和不存在的回执均返回 404。归档应用的已保存包仍可按游标分页、精确读取与导出；注入包摘要损坏后，三个读取入口均返回损坏错误。下一步接工作进程交接和实际资源核对。[公开交付合同](../contracts/development-task-delivery-v1.md#公开-http-面)

## 2026-11-25 单 Agent 工作进程交接与旧资源核对

隔离 SQLite 和短时测试子进程通过原生私有通道完成固定响应任务。首次启动返回持久回执，断开提交请求后继续运行；再次提交和重启后重提都只读原回执。准备失败、准备期间取消和宿主关闭均检查凭据吊销及执行槽。运行中分别读到模型调用、进程和代码环境的活动状态；正常结束后分别读到已关闭或已退出的证据。工作进程空闲时撤销执行权限，宿主会终止进程。模型调用尚未返回时取消任务，执行槽持续占用，直到该调用实际返回。

恢复测试创建并回收了测试自己的操作系统进程组，随后重开数据库。Docker 部分使用临时 CLI 替身检查命令和身份比对，覆盖外部任务、不同 Docker 实例、伪造容器 ID、镜像与账册绑定不符、标签查询与原 ID 查询不一致，以及重复核对。旧版数据库迁移后，缺少逐项账册的尝试保留未知状态和执行槽。实际 Docker 回收与冻结 SDK 联调由项目所有者另排。公开执行接口仍待接入。[公开交付合同](../contracts/development-task-delivery-v1.md#sqlite-实现与宿主接线)

## 2026-11-25 正式会话的固定响应任务执行

工作台新增显式的固定响应档案。正式会话可以准备确认、获得启动引用、读取尝试并请求取消。私有通道使用独立的固定响应后端，只识别冻结三文件任务。准备和首次启动按当前来源、执行环境、权限及确认摘要核验；相同请求的回执在服务重启且执行环境缺失时仍能找回。

隔离 HTTP 测试使用持久工作台同款 SQLite、正式 Cookie / CSRF 和工作进程私有协议。正常路径观测到四次固定响应与三次工具调用。工具替身暂停验证时，详情可读到第三个工具、候选摘要和起始时间。在这一位置取消，未返回的工具保留未决记录，资源核对另行完成。测试同时覆盖配置失效、重复启动、跨应用访问及角色撤销。真实 Docker 和冻结 SDK 留待单独联调。[公开交付合同](../contracts/development-task-delivery-v1.md#sqlite-实现与宿主接线)
