## 关键决策

- artifact 是不可变用户成果，lifecycle 是独立可变 owner；两者不能合并成同一 payload 或靠撤销既有不可变触发器实现归档。
- archive / unarchive 是独立受控 mutation，不从 parent session 的 read / write / execute 权限隐式提升；永久 purge 需要未来单独设计权限、保留期、显式确认与关联资源规则。
- C2 继续维持单一 strict artifact consumer；三类 Session surface 只保留 profile-specific turn contract，不新增平行结果 owner。
