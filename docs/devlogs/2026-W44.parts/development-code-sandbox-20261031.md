# 2026-10-31 固定 Go 代码沙箱与归属终止

## 授权与范围

起点为干净 `dev`、HEAD `081b59be`。项目所有者要求继续代码沙箱、受限文件与固定测试工具、资源归属终止，补齐专题 / 规划和文档，必要验证后提交；真实模型与用户试用继续暂停。沿用[集中任务卡](../../task-cards/development-task-probe-v1-plan.md)，不增加通用执行服务或新的检查器链。

本次单独确认真实容器窗口：复用已有 `golang:1.26.7-alpine3.23`、`linux/arm64` 镜像 `sha256:b17af760035fc2f338eed92d448a6c67f2d45438844fc6c60678fa5f99e44b57`，不构建、不下载依赖或镜像。Go 测试仅创建 / 启动 / 检查 / 按精确归属强制删除本次 `radishmind-code-sandbox_<随机身份>-tool_*` 容器。

非 root `65532:65532`、只读根、无网络、移除全部 capability、禁止提权；1 GiB 内存且无额外 swap、2 CPU、128 进程、256 文件描述符、512 MiB 临时区，无宿主端口、自动重启或 Docker 日志。只读挂载本次 watchdog 和 `tmp/development-sandbox-20261031/cases/` 中的三文件快照；不挂载原工作树、日常数据、数据库、秘密、Docker socket 或共享可写缓存。

## 实现

- `internal/developmentsandbox` 显式核对控制计划 / 委托 / 基准及可读写路径，复制私有候选；只读三文件、只可原子替换 `list.go`，拒绝链接、特殊 / 额外文件、受保护文件变化和旧文件摘要。尝试次数由控制计划限制，Probe 约束冻结输入与固定命令。
- 每次测试绑定精确候选摘要、另建全只读快照；固定 `go test -json -count=1 ./...` 在独立容器内执行。前后核对候选与快照，不在宿主机执行候选代码；替换后旧测试证据失效。
- 新增容器专用 Linux PID 1 watchdog，宿主直接调用明确拒绝；最长 120 秒硬期限退出整个 PID 命名空间，不依赖 SDK 或 Docker 附着进程。输出有界，超时 / 截断 / OOM / 非零退出都不能标记通过。
- 创建前同步归属账册，保存精确镜像 / watchdog / 请求 / 快照 / 名称 / ID；启动前核对实际配置和挂载，派发先记录。创建回执超时保留未知，没有对象也不伪造“创建未发生”；观察到并清理该对象后才能收口。
- 取消中断附着 CLI，但独立清理路径继续查询 / 校验 / 强制删除所属容器，再查询为空。显式 `CleanupRecovered` 严格读旧账册，只清理、不恢复或重放执行，拒绝损坏和越权身份。
- `WorkerLaunch.Sandbox` 冻结尝试 / 执行器 / 计划 / 基准，替代合成 handler；正常完成前必须确认沙箱关闭，失败 / 取消结合 SDK 空进程组、代码资源与本地模型活动连接记录终止。未知执行效果与用量不被抹掉。
- 新增私有 canonical schema / 合成样例，观察值记录实际命令、镜像 / watchdog、起止时间、耗时、退出码、OOM / 截断及输出，资源账册不代替 SQLite 尝试状态，也不是正式保存 / 导出包。

## 真实运行

首轮发现 Docker tmpfs 默认禁止执行，Go 编译后无法运行测试二进制；该失败没有被算作预期测试失败。修正为容器内显式 `exec` 临时区，仍保持 `nosuid,nodev`、只读源码与全部资源限制，第二轮四项通过；第三轮增加运行中遗留容器清理与输出超限，六项通过；第四轮包含命令 / 时间证据并使用 Go race，六项全部通过；第五轮以冻结配置的最终代码复验同一矩阵通过。随后发现候选可直接写容器 stdout 绕过 watchdog 子进程捕获，收紧 Go 的 Docker 捕获上限与截断标记，第六次定向验收对普通 / 直接输出两项负例均通过。失败输出保留，没有放宽断言或修改冻结测试。

| 检查 | 实际结果与证据范围 |
| --- | --- |
| 冻结任务 | 基准精确出现预期失败；仅修正 `list.go` 后 8 项子用例通过，来源基准不变，旧候选摘要拒绝 |
| 真实隔离与限额 | 源码 / 测试 / watchdog 写入失败、Docker socket 不存在、宿主合成秘密不继承、外网拒绝；磁盘与进程上限实际触发，明确观察标记后故意非零退出，不能冒充任务通过 |
