## 实现与根因修正

- Go `Runtime.RunWorker` 在启动前持久提交一次 `worker_claimed`，失败不重放。明确绝对命令与新建 `0700` 空目录，环境按白名单构造，秘密只经 stdin；没有安装工作台依赖或默认启用。
- Python 使用真实 `Agent / LocalConversation`、内存会话和唯一 `development_tool`。同步模型转换只调用 Go 专属通道；默认终端、文件工具、MCP、插件、动态上下文、condenser、critic、fallback 和其他模型入口关闭。SDK 本地能力标识不发起模型调用。
- 新增私有 canonical IPC schema：输入 / 报告 / 回执严格字段，帧数与大小有界、序号连续。SDK 报告先由 Go 事务提交再确认，只映射明确的来源事件，不传正文、推理、秘密或原始异常；未知事件拒绝。
- 工具必须绑定已持久入队的提议与摘要，由可信 Go `DispatchTool / CompleteTool` 给出观察值；nil handler 不伪造结果。本轮回调只返回合成值，没有文件 / 命令执行器；未来回调必须遵守取消上下文，真实操作由代码沙箱承担。
- 最终模型响应关闭后续调用并记录 `model_final_response`；只有 SDK 报告、正常 OS 退出、空进程组和最新资格均成立时，才同事务提交 `worker_exited / attempt_completed`。SDK 自报不能完成或取消任务。
- 独立取消路径软停止所属进程组，两秒后强制停止，并有界等待退出与空组；额外 FD 3 在 Go 父进程失联时使 Python 结束所属组。未确认清理写明未确认，不冒充完整沙箱终止。
- 修复 SQLite 同毫秒纯事件追加可能被无变化优化丢弃的问题；禁止超出 200 条的事件事务提交，避免写入后无法严格重读。为清理事件预留容量，并补充同毫秒、超限及失败不能完成的回归测试。
