## 关键决策

- Pencil 无限画布的顶层基准面默认横向排放；这是审阅顺序约束，不改变产品页面的响应式方向。
- 新增局部稿必须继承现有 Workbench 的页面骨架、密度、留白和信息所有权；只复用 token 不构成视觉继承，不以功能后加入为理由建立另一套配色或页面壳。
- 视觉继承必须同时覆盖 token、信息架构与表面形态；连续结构保持方正，业务表面和控件按职责使用统一圆角，不用“全部硬方形”或“全部胶囊化”替代形态判断。
- 连续事实数据可以使用表格行，待编辑字段不能沿用同一表达；类型化编辑器必须呈现真实控件、字段关系、局部帮助和精确错误归属，避免把表单退化为整页横向分割。
- 字段错误归属于精确字段；contract drift 与 authority 失败归属于提交区域并清空全部值。颜色不是 required、类型、失败或选中的唯一通道。
