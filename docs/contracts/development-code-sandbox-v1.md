# 受控开发：固定 Go 探针代码沙箱合同 v1

更新时间：2026-10-31

所属功能：[隔离代码执行与候选交付](../features/workflow/controlled-software-development-team/isolated-code-execution-and-delivery-v1.md)。当前实现只覆盖已冻结的三文件 Go 代表任务；不是通用仓库执行服务、正式开发产物或生产多租户沙箱。

## 接线与权威

可信 Go 宿主显式创建 `developmentsandbox.New(Config)`，核对已确认的 `Plan / Delegation`、基准摘要、精确可读 / 可写路径、镜像与 watchdog 摘要。探针计划提供文件集合、固定验证命令及单命令期限，尝试的模型 / 工具次数仍由独立确认的控制计划限制。依赖、镜像与运行影响须另按具体窗口授权；SDK / 模型不能选择 Docker 程序、镜像、挂载、命令或宿主目录。

`WorkerLaunch.Sandbox` 只接受绑定相同尝试、执行器、计划和基准的可信 `WorkerSandbox`，与旧合成 `ToolHandler` 不可同时使用。SDK 工具仍先由 Go 持久消费提议 / 预留，再调用 `HandleTool`；SDK 无法直接调用该 Go 对象。正常平台 / 工作台不创建此对象，没有公开启动路由或默认启用开关。

单次工具串行执行，重复请求身份拒绝；重启只提供显式 `CleanupRecovered`，不恢复对象、重新执行工具或重放命令。SQLite 仍是尝试状态、资格、事件与预算的权威；资源账册只记录容器归属和清理事实，不成为第二套任务状态机。

## 文件与验证边界

- 仅接受冻结集合 `go.mod / list.go / list_test.go`，每份文件 1 至 32768 字节、UTF-8 文本；拒绝符号链接、硬链接、特殊文件、额外文件与受保护文件变化。
- 原来源只读；新建 `0700` 私有候选目录，读路径须在计划内，仅 `list.go` 可替换。替换核对当前文件摘要，通过临时文件、同步写入与原子重命名完成；不提供删除、shell 或任意 patch 解释器。
- 测试请求必须精确匹配当前候选树摘要。Go 创建另一个只读快照，全部源码都以操作系统只读挂载进入容器；包括 `list.go`，因此测试代码也不能绕过文件工具写入源码。前后核对候选与快照身份。
- 只执行 `/usr/local/go/bin/go test -json -count=1 ./...`。不运行仓库启动脚本、Git hooks、用户自选命令或安装依赖。`GOPROXY / GOSUMDB` 关闭、`GOTOOLCHAIN=local`、`GOENV / GOWORK` 关闭，工具环境固定，不继承宿主秘密。

候选树摘要沿用探针的有序 `path + NUL + sha256 + LF` 算法。失败测试是可用的真实观察值，不冒充工具传输成功就代表测试通过；候选变化使旧测试证据失效。

## 容器与硬期限

每项验证创建独立容器，固定镜像摘要且 `--pull=never`，非 root `65532:65532`、只读根、无网络、移除全部 capability、禁止提权、不发布端口、不自动重启、不保留 Docker 日志。仅挂载可信 watchdog 和当前快照，两份均只读；不挂载原工作树、数据库、Docker socket、凭据或可写共享缓存。

档案限制为 1 GiB 内存且不允许额外 swap、2 CPU、128 进程、256 文件描述符；`/tmp` 为 512 MiB 临时文件系统，带 `nosuid,nodev`，明确允许执行该区编译出的测试二进制。缓存和构建临时文件均在此区域，任务结束不共享可写缓存。

`radishmind-development-sandbox` 只允许 Linux PID 1 运行，拒绝宿主机直接执行。独立 watchdog 最多 120 秒强制退出 PID 1，结束整个代码 PID 命名空间，覆盖编译、测试及遗留后代；它不依赖 SDK、工具回调或附着的 Docker CLI 存活。硬期限退出码为 `124`，输出超限为 `122`，不解释为通过。

## 归属与停止

创建前同步写入私有 `resources.json`，包含随机会话身份、尝试 / 执行器 / 计划 / 基准绑定、镜像 / watchdog 摘要及请求、快照、容器名称与身份。容器带精确会话与尝试 label；收到创建回执后先保存 ID，再核对实际配置和两份挂载，最后记录派发再启动。

取消会中断附着 CLI，并在独立清理上下文中按本次会话查询、核对镜像 / label / 名称 / ID，强制删除所属容器，最后再次查询为空。不会只凭本地 CLI 退出、PID 不存在或一次错误响应宣称资源已清理；不按名称前缀批量删除，不执行全局 prune。

若创建回执超时，保留 `create_unknown`；没有观察到对应对象时也不能推定创建绝未发生。后续显式归属清理观察到并删除该对象后可收口。Docker 不可用、归属不符、记录损坏或清理期限内无法核对均返回未确认，不发布成功结果。`CleanupRecovered` 只清理旧资源，不启动任何执行；由可信宿主在停止旧控制路径后显式调用。

活跃控制路径目标为五秒内发出强制终止、十秒内完成归属核对，受 Docker 响应影响时如实标未确认。宿主崩溃期间没有存活的控制路径，不声称仍满足十秒核对；PID 1 硬期限负责限制遗留执行，重启后显式清理核对。

SDK 正常结束后仍须沙箱清理确认，才提交 `sandbox_closed / worker_exited / attempt_completed`。失败 / 取消路径同时核对 SDK 退出与空进程组、代码资源为空、模型连接已离开活动集合，再由 Go 提交已有 `termination_recorded`；终止确认不抹除未知执行效果、未决用量或失败状态。

## 数据与证据

`contracts/development-code-sandbox.schema.json` 定义私有工具观察值与资源账册；不是公开 API 或正式交付 manifest。读取返回有界文本与文件 / 候选摘要，替换返回实际新摘要，测试返回固定命令、镜像 / watchdog 摘要、实际起止时间、耗时、退出码、OOM / 截断标记及有界输出。

watchdog 与 Go 的 Docker 输出捕获各自最多保留 65536 字节，SDK 观察值最多展示 8192 字节测试输出；截断、超时、OOM 或非零退出均不能标记 `command_passed`。完整可用输出、实际容器配置、退出状态及验证摘要保留在私有隔离目录。源码 / 测试输出不写入公共事件；这些本地证据尚不是用户保存的开发包或下载接口。

当前真实容器验收覆盖冻结基准 / 修正候选、只读挂载、宿主秘密不继承、网络拒绝、磁盘 / 进程上限、取消、硬期限、遗留运行容器清理和输出超限。SDK 收尾接线另有 Go 定向验证；本次未再次启动真实 SDK 或运行真实模型，不据分层证据宣布真实 SDK 与代码容器同次任务的联合验收、恶意代码安全或正式采用完成。运行入口见[模块说明](../../services/platform/internal/developmentsandbox/README.md)，历史证据见[本轮记录](../devlogs/2026-W44.parts/development-code-sandbox-20261031.md)。
